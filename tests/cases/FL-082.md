**Local**

- U `routers/simulator.test.ts`: cada acción arma el mismo sobre SNS firmado con el `clockId` del principal; `sendPhoto`/`sendVoiceNote` solo con un `uploadId` del mismo usuario y mundo, `HeadObject` y bytes mágicos; una clave de otro mundo o un `uploadId` de otro usuario → `FORBIDDEN`; funciona con `whatsappMode = simulated` aunque el stage tenga `live`.
- U `simulated.test.ts`: el transporte simulado valida el JSON de Meta, persiste y emite estados sintéticos.
- UI `simulator.spec.ts`: identidades, burbujas, plantillas con botones, listas, documentos, reacciones, acuse y "escribiendo…", rótulo "simulador" siempre visible, glosa "EN"; grabación de voz con el stream de audio falso de Chromium y un caso WebKit con `audio/mp4`; subida de foto contra el emulador de S3.
