# FL-065 · Tomar o cerrar un caso desde la consola

| Campo | Valor |
|---|---|
| Área | G · Escalamiento y supervisores |
| Actores · canal | Supervisor (consola) · consola, WhatsApp |
| Disparador | "Tomar" / "Cerrar" en la vista del caso |
| Reglas | `supervisorProcedure` |
| Pruebas | U `routers/cases.test.ts` · UI `cases.spec.ts` · SR `SC-07/7` |

## Entrada

- `SC-07`: un caso `OPEN` del mundo; principal `SUPERVISOR` (`usr-qa-sup`) y principal `OPS` (`usr-qa-ops`).
- `console.cases.take` y `console.cases.close` como `SUPERVISOR`; `console.cases.take` como `OPS`.

## Pasos

**SR · `SC-07`**

1. `SC-07/7` [det] tomar y cerrar desde la consola (`SUPERVISOR`); `OPS` → 403; `installer.settle`.

**Local**

- U `routers/cases.test.ts`: `cases.take` y `cases.close` con `supervisorProcedure`; encolan `SUPERVISOR_ACTION` → mismo `take_case`/`close_case`; `OPS` → 403.
- UI `cases.spec.ts`: botones "Tomar" y "Cerrar" en la vista del caso, estado actualizado.

## Resultado esperado

- Igual que FL-055 y FL-063 con `takenBy` = el usuario de consola: `Case TAKEN`, luego `CLOSED` con `closedBy`, y `AGENT_TURN(CASE_CLOSED)` encolado.
- Sin ventana del supervisor en WhatsApp, ningún `CASE_BRIEF` por WhatsApp (la consola ya muestra todo).
- `OPS`: 403, el caso no cambia, denegación en la bitácora.

## Oráculo

No aplica: el paso es `det` (el contenido del turno `CASE_CLOSED` no se asierta aquí).

## Evidencia

- `snapshot` del caso después de cada acción; código de respuesta por principal.
- Salientes de WhatsApp al supervisor (`CASE_BRIEF`: 0 sin ventana).
